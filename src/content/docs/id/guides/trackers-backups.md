Alat-alat ini bekerja lewat server Suwayomi, jadi tersedia di koleksi Server.

## Tracker

Buka **Trackers**, login ke situs tracker yang didukung server, lalu tambahkan judul ke tracker dari halaman judulnya. Progres diperbarui saat kamu membaca. Saat menghapus entri tracking, kamu bisa memilih untuk menghapusnya juga dari situs tracker.

## Backup

- **Create backup** menyimpan library, kategori, riwayat, dan tracking.
- **Restore backup** mengembalikannya. Fitur ini juga menerima **backup Mihon atau Tachiyomi** (`.tachibk`), jadi library dari Android bisa dibawa ke server Suwayomi.
- **Automated backup** membuat backup di server sesuai jadwal; atur interval, waktu, folder, dan berapa banyak yang disimpan.

## Migrasi

Kalau sebuah sumber berhenti bekerja, **Migrate** memindahkan judul ke sumber lain. Pilih apa yang ikut dipindah: chapter, kategori, tracking, unduhan, dan pengaturan reader. Bisa satu judul atau banyak sekaligus.
