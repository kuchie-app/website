## Koleksi Local

Pilih **Save to device** di sebuah chapter. Chapter disimpan di profil Local dan bisa dibuka tanpa koneksi.

## Koleksi Server

Ada dua jenis unduhan:

- **Download to server** memasukkan chapter ke antrean unduhan server.
- **On-device downloads** menyimpan chapter di iPhone untuk dibaca offline. Kuchie bisa menambahkannya otomatis saat kamu membaca.

Opsi yang berguna di pengaturan offline:

- **Download over Wi-Fi only**
- **Simultaneous downloads**
- **Auto-remove old downloads** setelah beberapa hari
- **Keep recently-read chapters downloaded**

## Live Activities

Saat chapter diunduh, progresnya tampil di Live Activities dan Dynamic Island. Pilih gaya yang kamu suka: syal penanda dengan cincin progres, atau wajah Kiri dengan persentase.

## Kosongkan ruang

Hapus unduhan per judul, atau pakai **Remove all downloads**. Library di server tidak tersentuh.
