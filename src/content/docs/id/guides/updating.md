## Pasang versi baru di atas yang lama

Pasang IPA baru dengan alat yang sama seperti sebelumnya. App akan diganti dan library, riwayat, pengaturan, serta unduhanmu tetap ada, karena bundle ID tetap `app.kuchie.reader`.

:::danger
Jangan hapus Kuchie sebelum update. Menghapus app juga menghapus datanya, termasuk unduhan di perangkat dan library Local.
:::

Kuchie juga mengecek GitHub dan memberi tahu saat ada versi baru. Perubahannya ada di [Changelog](/id/changelog/).

## Kalau app tidak bisa dibuka

Kalau kamu memakai Apple ID gratis, instalasi kedaluwarsa setelah tujuh hari. Refresh di AltStore atau SideStore (**My Apps → Refresh All**). Kedaluwarsa tidak menghapus data apa pun.

## Pindah ke iPhone baru

- **Koleksi Server:** pasang Kuchie di iPhone baru dan hubungkan ke server yang sama. Library dan progresmu ada di server.
- **Koleksi Local:** library ada di iPhone lama. Ekspor judul yang kamu impor sebagai file CBZ, lalu impor di iPhone baru.
