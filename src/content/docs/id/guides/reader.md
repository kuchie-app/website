## Mode baca

| Mode | Untuk |
| --- | --- |
| **Webtoon** | Strip vertikal panjang: manhwa, manhua, webtoon. Mode bawaan |
| **Paged (kanan ke kiri)** | Manga Jepang |
| **Paged (kiri ke kanan)** | Komik Barat |
| **Vertikal** | Per halaman, membalik ke bawah |

Atur mode per judul dari menu reader. **Auto reading mode** otomatis membuka manhwa, manhua, dan webtoon dalam mode webtoon.

## Bernavigasi

- **Tap zone** untuk membalik halaman. Bisa dibalik, diperkecil, atau ditampilkan sebentar saat reader dibuka.
- **Swipe** ke chapter berikutnya di akhir chapter, kalau dinyalakan.
- **Slider halaman** selalu mulai dari halaman 1 di kiri, apa pun arahnya.
- **Tekan lama** sebuah halaman untuk aksi halaman.

## Zoom dan tata letak

- **Cubit** atau **ketuk dua kali** untuk zoom. Keduanya bisa dimatikan.
- **Halaman ganda** menampilkan dua halaman berdampingan, dengan opsi membalik atau menggeser urutannya.
- **Crop borders** membuang margin putih; **Reader padding** menambah ruang di sekitar halaman.

## Liquid Glass

Di iOS 26, kontrol reader, pencarian, dan tab bar memakai Liquid Glass. Versi sebelumnya memakai kontrol standar dengan tata letak yang sama.
