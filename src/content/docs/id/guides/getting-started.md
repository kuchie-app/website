Kuchie adalah pembaca manga dan webtoon untuk iPhone yang gratis dan open source. Kuchie tidak menyediakan konten: kamu yang membawa file, extension store, atau server Suwayomi sendiri.

## Yang dibutuhkan

- iPhone dengan **iOS 15 atau lebih baru**. Kontrol Liquid Glass muncul di iOS 26; versi sebelumnya memakai kontrol standar.
- **Apple ID**. Akun gratis bisa; akun developer berbayar membuat instalasi bertahan setahun, bukan tujuh hari.
- Untuk sebagian besar cara instal, **Mac atau PC Windows** untuk instalasi pertama.

## Versi singkat

1. [Pasang Kuchie](/id/guides/install/) dengan AltStore, SideStore, atau akun developer sendiri.
2. Buka Kuchie dan pilih koleksi:
   - **Local** kalau ingin semuanya di iPhone. Lalu [impor file](/id/guides/local-library/) atau [tambahkan extension store](/id/guides/extension-stores/).
   - **Server** kalau kamu menjalankan [Suwayomi](/id/guides/server-setup/). Lalu [hubungkan](/id/guides/server-connect/).
3. Buka sebuah judul, ketuk chapter, dan mulai membaca. [Panduan membaca](/id/guides/reader/) menjelaskan mode dan gestur.

## Local atau Server?

| | Local | Server |
| --- | --- | --- |
| Tempat library | Di iPhone | Di server Suwayomi milikmu |
| Menambah judul dari | File CBZ/ZIP, folder gambar, extension store | Sumber di server |
| Riwayat dan progres | Di iPhone | Tersinkron dengan server |
| Tracker, backup, migrasi | — | Ya, lewat server |
| Tanpa komputer menyala | Bisa | Server harus terjangkau (chapter offline tetap bisa dibaca) |

Kamu bisa ganti kapan saja dari **Library** atau **More → Collection mode**. Setiap koleksi punya library sendiri, jadi berganti koleksi tidak mencampur atau menghapus apa pun.

:::tip
Masih bingung? Mulai dengan **Local** dan impor satu file CBZ. Server bisa ditambahkan nanti.
:::
