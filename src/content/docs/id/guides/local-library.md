Koleksi Local menyimpan semuanya di iPhone: library, riwayat, progres baca, dan unduhan. Tidak perlu server atau komputer.

## Pilih Local

Pilih **Local** saat pertama membuka Kuchie. Kalau sedang di Server, ganti dari **Library** atau **More → Collection mode**.

## Impor file

Kuchie bisa mengimpor:

- Arsip **CBZ** dan **ZIP** berisi gambar, satu chapter atau volume per file.
- **Folder gambar**, dibaca berurutan sesuai nama file.

Halaman bisa berformat JPG, PNG, GIF, WebP, BMP, atau AVIF. CBR, CB7, PDF, dan EPUB belum didukung; ubah dulu ke CBZ.

1. Taruh file di tempat yang bisa dilihat app Files: On My iPhone, iCloud Drive, atau drive yang tersambung.
2. Di library Local Kuchie, ketuk **Import manga** lalu pilih file atau folder.
3. Judulnya muncul di library. Buka dan ketuk sebuah chapter untuk membaca.

:::tip
Beri nama halaman dengan angka nol di depan (`001.jpg`, `002.jpg` …) supaya urutannya benar.
:::

## Simpan chapter dari extension

Judul dari [extension store](/id/guides/extension-stores/) dimuat langsung dari situsnya. Untuk menyimpan chapter agar bisa dibaca offline, pilih **Save to device**. Chapter tersimpan tetap ada di profil Local sampai kamu menghapusnya.

## Pindah antar koleksi

Local dan Server terpisah, termasuk unduhannya. Memindahkan library dari satu koleksi ke koleksi lain belum bisa.

## Lokasi file

Semuanya tersimpan di penyimpanan Kuchie sendiri di iPhone. Kalau app dihapus, library Local ikut terhapus, jadi [update](/id/guides/updating/) dengan memasang di atas versi lama.
