## Categories

- **Add category** from the library menu. Rename, hide or delete categories when editing them; deleting one moves its titles to **Default**.
- Choose a **default category** for new titles.
- Turn on **Show category tabs** to switch categories with tabs.
- Sorting and filters can be set **per category**.

## Filters and sorting

Filter by unread, downloaded, tracking, tags and more. Sort by title, last read, rating, tracker score and others. Unread and download badges can be reordered; drag them, or move a badge to the other corner.

## Tags, notes and ratings

Open a title to add **tags**, **notes** and **your rating**. Plain words in the library search match the title, author, genres and tags.

## Duplicates

**Scan for duplicates** lists titles that look like the same series, for example the same tracker entry added twice, so you can merge or remove them.
