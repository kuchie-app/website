## Reading modes

| Mode | For |
| --- | --- |
| **Webtoon** | Long vertical strips: manhwa, manhua, webtoons. The default |
| **Paged (right to left)** | Japanese manga |
| **Paged (left to right)** | Western comics |
| **Vertical** | Paged, flipping down |

Set a mode per series from the reader menu. **Auto reading mode** opens manhwa, manhua and webtoons in webtoon mode for you.

## Moving around

- **Tap zones** turn pages. You can invert them, make them smaller, or show the zones briefly when the reader opens.
- **Swipe** to the next chapter at the end of one, if that's turned on.
- The **page slider** starts at page 1 on the left in every direction.
- **Long tap** a page for page actions.

## Zoom and layout

- **Pinch** or **double tap** to zoom. Either can be turned off.
- **Double pages** shows spreads side by side, with options to invert or offset them.
- **Crop borders** removes white margins; **Reader padding** adds space around pages.

## Liquid Glass

On iOS 26 the reader controls, search and tab bar use Liquid Glass. Earlier versions use the standard controls with the same layout.
