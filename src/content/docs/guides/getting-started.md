Kuchie is a free, open-source reader for manga and webtoons on iPhone. It doesn't come with any content: you bring your own files, extension stores or Suwayomi server.

## What you need

- An iPhone with **iOS 15 or later**. Liquid Glass controls appear on iOS 26; earlier versions get the standard controls.
- An **Apple ID**. A free one works; a paid developer account makes installs last a year instead of seven days.
- For most install methods, a **Mac or Windows PC** for the first install.

## The short version

1. [Install Kuchie](/guides/install/) with AltStore, SideStore or your own developer account.
2. Open Kuchie and pick a collection:
   - **Local** if you want everything on the iPhone. Then [import files](/guides/local-library/) or [add an extension store](/guides/extension-stores/).
   - **Server** if you run [Suwayomi](/guides/server-setup/). Then [connect to it](/guides/server-connect/).
3. Open a title, tap a chapter and start reading. The [reader guide](/guides/reader/) covers modes and gestures.

## Local or Server?

| | Local | Server |
| --- | --- | --- |
| Where your library lives | On the iPhone | On your Suwayomi server |
| Add titles from | CBZ/ZIP files, image folders, extension stores | Your server's sources |
| History and progress | On the iPhone | Synced with the server |
| Trackers, backups, migration | — | Yes, through the server |
| Works without a computer running | Yes | Needs the server reachable (offline chapters still work) |

You can switch any time from **Library** or **More → Collection mode**. Each collection keeps its own library, so switching never mixes or deletes anything.

:::tip
Not sure? Start with **Local** and import one CBZ file. You can add a server later.
:::
