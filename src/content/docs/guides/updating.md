## Install the new version over the old one

Install the new IPA with the same tool you used before. It replaces the app and keeps your library, history, settings and downloads, because the bundle ID stays `app.kuchie.reader`.

:::danger
Don't delete Kuchie before updating. Deleting the app deletes its data, including on-device downloads and the Local library.
:::

Kuchie also checks GitHub for new versions and tells you when one is out. What changed is on the [Changelog](/changelog/).

## When the app won't open

If you used a free Apple ID, the install expires after seven days. Refresh it in AltStore or SideStore (**My Apps → Refresh All**). Expiring doesn't remove any data.

## Moving to a new iPhone

- **Server collection:** install Kuchie on the new iPhone and connect to the same server. Your library and progress are on the server.
- **Local collection:** your library lives on the old iPhone. Export the titles you imported as CBZ files and import them on the new one.
